# Sample images

## DogFLW samples

`sample_dog_1.png` through `sample_dog_5.png` are images from the
[DogFLW dataset](https://github.com/martvelge/DogFLW) by Martvel, Zamansky,
Pedretti, Canori, Shimshoni and Bremhorst (Tech4Animals Lab, University of
Haifa).

**Modified:** each image has the dataset's own ground-truth facial landmark
annotations and face bounding box rendered onto it. The landmarks shown are
DogFLW ground truth, not this package's model output.
